# InterviewPilot

## תיאור הפרויקט

InterviewPilot הוא סוכן AI המסייע למועמדים להתכונן לראיונות עבודה בתחום התוכנה והפיתוח.

## הבעיה שהפרויקט פותר

מועמדים בתחילת דרכם המקצועית מתקשים לעיתים לזהות אילו נושאים עליהם ללמוד, כיצד לענות על שאלות מקצועיות וכיצד לזהות פערי ידע.

## הפתרון

הסוכן מנהל תהליך תרגול אינטראקטיבי, אוסף מידע על התפקיד ועל הידע של המשתמש, מציג שאלות מקצועיות ומתאים את המשך התרגול לתשובות המתקבלות.

## אופן פעולת הסוכן

1. איסוף מידע על התפקיד ועל מטרת התרגול.
2. ניתוח המידע באמצעות מודל שפה של OpenAI.
3. בחירת הצעד הבא בהתאם לתשובות המשתמש.
4. שימוש בכלי לשמירת שאלות ותשובות בהיסטוריית התרגול.
5. התאמת המשך התרגול למידע שנאסף.
6. סיום התהליך כאשר המשתמש מסיים את התרגול או כאשר נדרש לעצור.

## טכנולוגיות

- Python
- OpenAI API
- FastAPI
- LangGraph
- React
- Vite
- JSON לשמירת היסטוריית התרגול

## התקנה והפעלה

### דרישות מקדימות

- Python 3.11
- Node.js ו־npm
- מפתח API של OpenAI

### 1. התקנת תלויות ה־Backend

מתיקיית הפרויקט הראשית, הפעילו את הסביבה הווירטואלית והתקינו את התלויות:

```powershell
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### 2. הגדרת מפתח API

צרו קובץ `.env` בתיקיית הפרויקט הראשית והגדירו בו את מפתח ה־API של OpenAI, באמצעות שם המשתנה שבו משתמש הקוד.

אין לפרסם את המפתח או להעלות את קובץ `.env` ל־GitHub.

### 3. הפעלת השרת

מתיקיית הפרויקט הראשית, הפעילו:

```powershell
python -m uvicorn server:app --host 127.0.0.1 --port 8765
```

בדיקת זמינות השרת:

http://127.0.0.1:8765/api/health

תיעוד ה־API:

http://127.0.0.1:8765/docs

### 4. התקנת והפעלת ה־Frontend

פתחו טרמינל נוסף, היכנסו לתיקיית `frontend` והפעילו:

```powershell
cd frontend
npm install
npm run dev
```

פתחו בדפדפן את כתובת ה־Local שמוצגת בטרמינל של Vite.

## אבטחה

אין להעלות ל־GitHub מפתחות API, קובצי `.env` או מידע אישי מתוך היסטוריית התרגול.
